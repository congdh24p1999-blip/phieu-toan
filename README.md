# Xưởng Phiếu Toán

Công cụ tạo phiếu luyện Toán lớp 1 miễn phí cho phụ huynh: chọn dạng bài, phạm vi số, in khổ A4 kèm trang đáp án.

Dùng ngay: https://congdh24p1999-blip.github.io/phieu-toan/

- Toàn bộ app nằm trong một file `index.html` (HTML, CSS, JavaScript thuần), không cần máy chủ.
- Nội dung bám yêu cầu cần đạt môn Toán lớp 1, Chương trình GDPT 2018; bài tập tự soạn, không sao chép SGK.
